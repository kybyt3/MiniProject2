# MiniProject2

## This Mini Project is an implementation of a Student Academic Research Assistant using LangChain inside of Python
This agent is designed to help students with academic tasks and is designed to go beyond answering questions. It will decide when to use certain tools.
Example uses for this agent is planning study sessions, answering questions based on course provided documentation, checking a draft against a rubric, etc. 

## Technical Requirements for this Project
- Uses LangChain
- Implement at least 3 different tools for common student workflows
- Short and long-term memory capabilities
- Demonstrates rational agent behavior (asking clarification, handling missing info, and using appropriate tools)

# Goals for this project
The goal of this project is developing a small, but functional AI agent that can work with user requirements to provide them with a tailored experience
and ensure that the agent provides logical help to the user.
